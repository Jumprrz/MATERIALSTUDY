# MSE250 — upload these files together

1. Extract this ZIP and open the extracted folder.
2. GitHub repository → Add file → Upload files → Choose your files.
3. Select ALL files in this folder and upload them to the repository root. Keep their filenames unchanged. Accept replacement of matching old files.
4. Commit changes.
5. Settings → Pages → Deploy from a branch → main → /(root) → Save.
6. Open the published URL. Select an exam, then select the requested textbook PDF locally.

Use /(root), NOT /docs, for this package. It has no subfolders and needs no Python or build step. Old docs folders can remain unused. If you previously opened the old app, refresh after publication; if an old cached version persists, export progress before clearing site data.

All five exams are included. PDF textbooks are not bundled or uploaded. The final includes 80 clearly labeled original-book references because Book 5 lacks the promised Chapters 1–20 review copies. Source issues remain flagged and excluded from mastery scoring.
